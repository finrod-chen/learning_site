# iPAS 淨零碳規劃管理師考點心智圖

## 第一章 極端氣候下國際因應歷程與趨勢

### 1.1 聯合國氣候變遷大會(COP)歷程與重要決議
- **UNFCCC 時間軸**
  - 1992年5月通過公約 → 1992年6月里約地球高峰會開放簽署（154國簽署）→ 1994年3月21日正式生效
  - 1995年Berlin召開COP1（第一次締約方會議）
  - 考點陷阱：UNFCCC通過年份(1992) ≠ 生效年份(1994) ≠ COP1召開年份(1995)
- **京都議定書 (1997通過 / 2005生效)**
  - 減量目標：附件一國家以1990年為基準，平均減量 **5.2%**
    - 歐盟及東歐：**-8%**｜美國：**-7%**｜日本、加拿大、匈牙利、波蘭：**-6%**
    - 冰島：**+10%**｜澳洲：**+8%**｜挪威：**+1%**
  - 減量時程：**2008–2012年**（5年平均）
  - 彈性機制：CDM、ET、JI → 考點陷阱：ESI 非彈性減量機制
  - COP17(2011)：將 NF₃（三氟化氮）列為第7種溫室氣體
- **巴黎協定 (COP21 / 2015通過 / 2016生效)**
  - 目標：將全球升溫控制在 **遠低於 2°C**，並努力限制在 **1.5°C** 以內
  - NDC 提交週期：**每5年一次**（考點陷阱：非每3年）
  - 三大支柱：Finance（資金）、Technology（技術）、Capacity-Building（能力建構）
  - COP27(2022)：設立「損失與損害資金」初步共識
  - COP28(2023)：正式通過 FRLD（損失與損害基金），截至2024年9月承諾總額 **7.2億美元**
  - COP29(2024)：聚焦氣候財務，通過 NCQG（新集體量化氣候財務目標）
- **COP 年度大事記（考試頻繁）**
  - COP1(1995柏林) → COP3(1997京都議定書) → COP7(2001馬拉喀什) → COP11(2005蒙特婁，京都生效)
  - COP13(2007峇里島路線圖) → COP15(2009哥本哈根協議) → COP16(2010坎昆，綠色氣候基金法制化)
  - COP17(2011德班，NF₃列入) → COP18(2012多哈，第二承諾期2013-2020)
  - COP19(2013華沙，INDCs) → COP20(2014利馬) → COP21(2015巴黎協定)
  - COP22(2016馬拉喀什實施細則) → COP23(2017波昂，斐濟主持調適) → COP24(2018卡托維茲規則書)
  - COP25(2019馬德里，碳市場未達共識) → COP26(2021格拉斯哥，美國重新加入)
  - COP27(2022沙姆沙伊赫) → COP28(2023杜拜) → COP29(2024巴庫)
  - 考點陷阱：2020年因 COVID-19 **未舉行實體會議**

### 1.2 國內外極端氣候變遷治理與因應作法
- **UNFCCC 四大原則**
  - 共同但有區別的責任（CBDR）
  - 預防原則：科學不確定性不作為延遲措施之理由
  - 可持續發展權
  - 不構成國際貿易任意或無理歧視手段
- **台灣 2050 淨零路徑（國家因應氣候變遷行動綱領，112.11）**
  - 願景：建構能適應氣候風險之 **低碳家園**
  - 目標：**139年（2050年）** 溫室氣體淨零排放
  - 四大面向：氣候變遷調適 / 溫室氣體減量 / 政策配套 / 公正轉型
  - 考點陷阱：台灣 **不以新增核能發電** 作為因應氣候變遷措施
- **碳邊境調整機制 (CBAM)**
  - 歐盟推行，防堵 **碳洩漏**
  - 對境外含碳貨物課徵碳稅，使進口碳成本 ≥ 歐盟境內製造成本

### 1.3 淨零排放專有名詞解釋
- **基礎概念**
  - 氣候變遷調適(Adaptation)：人類與自然系統回應氣候風險的調整過程
  - 碳中和(Carbon Neutrality)：特定範疇內，人為CO₂排放量 = 人為CO₂移除量
  - 淨零排放(Net Zero)：溫室氣體排放量 = 碳匯量（範圍廣於僅CO₂）
  - 淨二氧化碳排放(Net Zero CO₂)：特定時期內CO₂排放量 = CO₂移除量
  - 負排放(Negative Emissions)：藉由人類活動主動移除大氣中溫室氣體（超出自然碳循環）
- **碳定價與市場機制**
  - 碳定價(Carbon Pricing)：減緩政策的 **經濟手段**（非懲罰/獎勵）
  - 總量管制與排放交易(Cap and Trade)：設定排放上限 → 劃分可交易額度 → 允許買賣
  - 碳洩漏(Carbon Leakage)：產業移至碳管制寬鬆國家再輸入，反而增加總排放量
- **CCUS 與 GWP**
  - CCUS：捕捉→壓縮運輸→廣泛應用 或 注入地底深層永久儲存
  - GWP（全球暖化潛勢）：特定時間區間內，單位質量溫室氣體輻射衝擊相對於CO₂的指數

## 第二章 企業淨零碳規劃管理職能基準（T1/T2/T3）

### T1 統籌並建立碳盤查與碳足跡管理制度
- **T1.1 建置組織內部碳盤查與碳足跡作業機制**
  - 產出文件：O1.1.1 作業機制說明 → O1.1.2 教育訓練手冊 → O1.1.3 SOP管理規範文件（需公司主管同意）
  - 關鍵標準：
    - K01 **ISO 14064-1**：溫室氣體盤查標準（組織層級）
    - K02 **ISO 14067**：產品碳足跡盤查標準
    - K03 **ISO 14044**：生命週期評估標準
  - 考點陷阱：ISO 14064-1 是組織層級盤查，ISO 14067 是產品層級碳足跡
- **T1.2 彙整及分析碳盤查與碳足跡資料**
  - 產出文件：O1.2.1 溫室氣體查證聲明書 / O1.2.2 產品碳足跡查證聲明書
  - 考點陷阱：查證聲明書需由 **第三方** 產出，非內部自評

### T2 規劃企業落實淨零永續目標之策略藍圖
- **T2.1 建立/維運企業淨零永續發展機制**
  - 建立 **淨零委員會**（邀集經營團隊或權責主管）
  - 需經 **董事會或委員會主席核定** 後實施
- **T2.2 因應氣候變遷協助企業建立內部推動藍圖**
  - 四大運作模式：
    - K19 達成淨零目標之 **能源供給** 運作模式
    - K20 達成淨零目標之 **循環再生** 運作模式
    - K21 達成淨零目標之 **低碳導入** 運作模式
    - K22 達成淨零目標之 **負碳加值** 運作模式
  - 考點陷阱：四者順序與差異需清楚辨識
- **T2.3 建立淨零供應鏈管理機制**
  - 產出：O2.3.1 淨零供應鏈管理規定與淨零目標設定 / O2.3.2 供應商碳排調查表
  - 關鍵知識：K24生產管理 / K25物料管理 / K26產品知識 / K27利害關係人影響性 / K29採購規範 / K30運輸規範 / K31供應商管理 / K32供應商評選

### T3 執行企業落實淨零永續目標之發展
- **T3.1 歸納國內外永續發展評比資料**
  - 重點：研析永續評比問卷撰寫要點，包含供應鏈 ESG 氣候相關財務揭露建議(TCFD)
  - 關鍵標準：K33 國際環保標準 / K34 企業社會責任規範 / K35 國內外永續評比標準與指數
  - 考點陷阱：TCFD 是「氣候相關財務揭露」框架，非獨立評比
- **T3.2 撰寫 ESG 報告書中淨零碳排放之成果**
  - 彙整淨零執行成果於 ESG 報告，供利害關係人理解，並滾動精進以保持承諾
  - 關鍵知識：K36 環境面管理 / K37 GRI/TCFD/SBTi/RE100/CDP/SDG/DJSI 永續治理概念

## 考試常見陷阱彙整
- UNFCCC 生效年份(1994) ≠ COP1召開年份(1995) ≠ 京都議定書通過年份(1997)
- 京都議定書減量目標是 **5.2%**（非 3.2% 或 6.3%）
- 巴黎協定目標是 **遠低於 2°C**，努力限制在 **1.5°C**（順序不可顛倒）
- NDC 更新週期是 **每5年**（非每3年）
- 台灣淨零目標年份是 **139年（2050年）**（非112年或120年）
- 台灣 **不新增核能** 作為氣候變遷對策
- 碳定價是 **經濟手段**（非懲罰或獎勵）
- 查證聲明書需由 **第三方** 產出
- ISO 14064-1（組織層級）≠ ISO 14067（產品層級）
- COP28 正式通過 **損失與損害基金(FRLD)**（COP27僅初步共識）
- 京都議定書彈性機制不含 **ESI**
