碳中和(Carbon Neutrality)定義 :: 特定範疇內人為CO2排放量與移除量達平衡（口訣：碳中僅限CO2平衡）
淨零排放(Net Zero)定義 :: 溫室氣體總排放量與碳匯量達平衡（涵蓋所有GHG）（口訣：淨零全氣體平衡）
碳中和 vs 淨零 核心差異 :: 碳中和僅限CO2；淨零涵蓋全部六類以上溫室氣體（口訣：中碳CO2淨全氣）
氣候變遷調適(Adaptation) :: 人類與自然系統回應實際或預期氣候風險之調整過程（口訣：調適應風險）
碳洩漏(Carbon Leakage) :: 產業外移碳管鬆處再輸入，致全球排放反而增加（口訣：碳漏外移反增排）
碳定價(Carbon Pricing) :: 為排放訂價之經濟工具（碳稅/費、排放交易）（口訣：定價抑排經濟手）
總量管制與排放交易(Cap and Trade) :: 設定排放上限並劃分可交易額度之市場機制（口訣：上限交易市機制）
全球暖化潛勢(GWP) :: 特定GHG單位質量脈衝排放之輻射衝擊相對於CO2之指數（口訣：GWP比CO2輻射力）
二氧化碳當量(CO2e) :: 不同GHG依GWP換算之統一比較單位（口訣：CO2e換算同基準）
ISO 14064-1 適用範疇 :: 組織層級溫室氣體盤查與查證標準（口訣：一四零六四組織查）
ISO 14067 適用範疇 :: 產品碳足跡(CFP)盤查與標示標準（口訣：一四零六七產足跡）

間接溫室氣體排放(Indirect GHG) :: 由營運活動產生但非組織控制之源（範疇二、三）（口訣：間排因營運但非控）
重大間接溫室氣體排放 :: 經組織量化報告且符合訂定重大性準則之排放（口訣：重大間排依準則）
溫室氣體盤查清冊(GHG Inventory) :: 記錄GHG源、匯及量化排放移除之清單（口訣：盤查清冊源匯列）
基準年(Base Year) :: 用於逐時比較之特定歷史期間（口訣：基準年對照起點）
產品碳足跡(CFP)定義 :: 產品系統中GHG排放與移除總和，依LCA以CO2e表示（口訣：CFP全週CO2e計）
功能單位(Functional Unit) :: 量化產品系統績效之參照基準（口訣：功能單位定基準）
生命週期評估(LCA)四階段 :: 目標範圍→盤查分析→衝擊評估→闡釋（口訣：目盤衝闡四步走）
一級數據(Primary Data) :: 直接量測或原始來源取得之過程數據（口訣：一級直測最準確）
二級數據(Secondary Data) :: 資料庫、文獻、預設係數等代表性數據（口訣：二級間接推估用）
截斷準則(Cut-off Criteria) :: 排除不顯著物料/能源/排放之規範門檻（口訣：截斷捨棄不重要）
關鍵性審查(Critical Review) :: 確保CFP研究符合標準原則之第三方檢視（口訣：關鍵審查保一致）
